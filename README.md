# Telegram-бот для изучения английских слов

Бот на aiogram 3 и SQLite: тренировка произношения и перевода, таблица баллов,
статистика, загрузка слов с сайта или ручной ввод.

## Что реализовано в базовой версии

- Загрузка слов по ссылке (BeautifulSoup), выбор Unit и Part, ручной ввод при ошибке.
- Озвучивание слова (gTTS), ответ голосом или текстом, проверка синонимов и вариантов перевода.
- Нераспознанная речь не штрафуется, пропуск — ошибка для баллов.
- Редактируемая таблица баллов (кнопки: добавить, изменить диапазон, баллы -5..+5, удалить, восстановить).
- Баллы начисляются один раз за тренировку; повторы ошибок баллов не дают.
- Статистика, история, баланс, редактирование слов командами, настройки.
- Защита URL: только http/https, без localhost, частных IP и логина в ссылке; проверка редиректов.
- Тренировка хранится в БД и продолжается после перезапуска.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # впишите BOT_TOKEN
```

## Запуск

```bash
python -m bot.main
```

## Тесты

```bash
python -m pytest -q
```

Тесты не требуют Telegram, сети или ключей: логика баллов, проверка ответов,
БД, парсер, безопасность URL, сквозной сценарий обработчиков с фейковым ботом.

## Распознавание речи

По умолчанию (`STT_PROVIDER=none`) голосовые ответы недоступны, бот просит отвечать текстом.

Варианты:
- **OpenAI Whisper API** (`STT_PROVIDER=openai`, нужен `OPENAI_API_KEY`) — платно, высокое качество русского.
- **Vosk** — бесплатно и офлайн, нужна модель `vosk-model-small-ru` и ffmpeg для конвертации OGG в WAV.
- **Yandex SpeechKit / Google Cloud Speech-to-Text** — платно, есть бесплатные квоты.

Озвучивание через gTTS использует онлайн-сервис Google без ключа; при сбое бот показывает слово текстом.

## Ограничения

- Состояние ввода текста (например, ожидание ссылки) хранится в памяти и теряется при перезапуске;
  сама тренировка и данные сохраняются.
- Загрузка слов работает для страниц с HTML-таблицами «слово | перевод» и заголовками «Unit N» / «Part X».
  Другие структуры сайтов потребуют доработки парсера в `bot/scraper.py`.

## Telegram Mini App

Мини-приложение использует те же модули и ту же базу данных, что и бот. Экраны: тренировка
(Unit/Part, озвучка, голосовые ответы), мои слова, статистика, баллы, настройки и таблица баллов, источник слов.

### Запуск

```bash
uvicorn miniapp.server:get_app --factory --host 0.0.0.0 --port 8000
```

Telegram открывает мини-приложение только по HTTPS. Для теста можно получить временный адрес:
`cloudflared tunnel --url http://localhost:8000` (или разместить приложение на хостинге с HTTPS).
Полученный адрес укажите в `.env` как `MINIAPP_URL=https://...`, перезапустите бота и отправьте ему `/app`.

### Проверка в браузере без Telegram

В `.env` поставьте `MINIAPP_DEV_MODE=1`, откройте `http://localhost:8000/?dev=<ваш_telegram_id>`.
Этот режим отключает проверку подписи, поэтому **не включайте его на публичном сервере**.

### Голос в приложении

- Озвучивание слов — встроенный синтез речи браузера (`speechSynthesis`), работает без ключей.
- Голосовой ввод — Web Speech API (`SpeechRecognition`). Надёжно работает в Chrome и Android WebView Telegram.
  В iOS Telegram голосовой ввод может быть недоступен: тогда ответ пишется текстом.
  Ответ можно дать текстом в любом случае.
- Для распознавания нужен доступ к микрофону, который Telegram запросит при первом нажатии.

### Тесты

Тесты API и проверки подписи Telegram входят в общий набор: `python -m pytest -q`.
